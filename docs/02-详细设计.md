# WatchDesk 详细设计

## 0. 架构根基：边界 / 内部分离

### 0.1 核心原则

```
所有不安全、需防御、需回退的逻辑只在边界层出现一次。
边界之内，TypeScript 类型系统保证零防御代码。

                     ┌─────── 边界层 (Boundary) ───────┐
                     │  Parse / Validate / Normalize    │
                     │  所有可选链、兜底、try/catch      │
                     │  产生 Result<T, E> 或 Branded T  │
                     │                                   │
  Raw / Unsafe  ────►│  IPC • DOM Event • Native FFI    │──────►  Type-Safe Internal
  (外部输入)         │  FileSystem • Network             │        (内部纯类型逻辑)
                     │                                   │
                     └───────────────────────────────────┘
```

|                        | 边界层                 | 内部层                        |
| ---------------------- | ---------------------- | ----------------------------- |
| `?.` 可选链            | 集中出现               | **禁止**                      |
| `??` 兜底              | 集中出现               | **禁止**                      |
| `try/catch`            | 集中出现               | **禁止** (用 Result)          |
| `if (x == null)`       | 集中出现               | **禁止** — 类型已保证非空     |
| `zod` / valibot schema | 集中出现               | 不需要                        |
| 运行时类型检查         | 集中出现               | **禁止** — 编译时已保证       |
| 类型                   | `unknown` → 解析 → `T` | 精确类型 (零 `any`/`unknown`) |

### 0.2 边界清单

| 边界                     | 输入类型                        | 解析产物                     | 所属层                    |
| ------------------------ | ------------------------------- | ---------------------------- | ------------------------- |
| IPC `ipcMain.handle`     | `unknown` args                  | Use Case Input DTO           | Main / ipc                |
| Preload `contextBridge`  | Renderer 调用                   | Main 可理解的结构            | Preload                   |
| Native Adapter           | napi `Uint8Array` / JSON string | Domain Entity / Value Object | Main / infra              |
| Electron Repo (Renderer) | `window.electronAPI` 调用       | Use Case 返回值              | Renderer / infrastructure |
| DOM Event Handler        | `Event` 对象                    | 领域动作                     | Renderer / components     |
| File System Watch        | OS 原生事件                     | `FileChangeEvent[]`          | Main / infra              |
| electron-updater         | updater 事件                    | `UpdateStatusDTO`            | Main / updater            |
| `di.ts`                  | 运行时环境                      | 具体 Repo 实例               | Renderer / infrastructure |

```typescript
    const worker = this._getNextWorker();
    if (worker) {
      return this._dispatch(worker, task);
    }
    return this._enqueue(task);
```

```typescript
// ===== packages/desktop/src/main/workers/hash-worker.ts =====

/**
 * Worker 线程内部 — 纯计算，无 Electron 依赖
 * 接收 Uint8Array via postMessage → 哈希 → 返回 Uint8Array
 */

import { parentPort } from "node:worker_threads";
import { blake3 } from "@napi-rs/blake-hash";
import xxhash from "xxhash-wasm";

parentPort?.on("message", async (task: WorkerTask) => {
  try {
    switch (task.type) {
      case "hash:blake3": {
        // CPU 密集：blake3 哈希
        const hash = blake3(task.data); // returns Uint8Array
        const transferred = transfer(hash); // move ownership, not copy
        parentPort?.postMessage({ id: task.id, ok: true, data: transferred });
        break;
      }
      case "hash:xxhash64": {
        const h = await xxhash(); // xxhash-wasm
        const hash = h.h64Raw(task.data); // returns bigint
        parentPort?.postMessage({ id: task.id, ok: true, data: hash });
        break;
      }
      case "compress:zstd": {
        // Phase 2: 由 Rust tokio 执行，不经过 Worker
        break;
      }
    }
  } catch (err) {
    parentPort?.postMessage({ id: task.id, ok: false, error: String(err) });
  }
});
```

### 1.5 Rust 并发 (napi-rs, Phase 2)

```rust
// ===== packages/native/src/lib.rs (Phase 2) =====

use napi::bindgen_prelude::*;
use tokio;
use rayon;

/// tokio 协程：并发读取多个文件
/// 每个文件独立 tokio::spawn，I/O 并行
#[napi]
pub async fn read_many_raw(paths: Vec<String>) -> Result<Vec<Buffer>> {
    let tasks: Vec<_> = paths.into_iter()
        .map(|p| tokio::spawn(async move {
            tokio::fs::read(&p).await
        }))
        .collect();

    let results = futures::future::join_all(tasks).await;
    results.into_iter()
        .map(|r| r.map_err(|e| napi::Error::from_reason(format!("{}", e)))?)
        .map(|bytes| bytes.map(Buffer::from).map_err(|e| napi::Error::from_reason(format!("{}", e))))
        .collect()
}

/// rayon 线程池：并行哈希多个文件内容
/// 每个文件的数据已经在 Vec<u8> 中，CPU 并行计算哈希
#[napi]
pub fn hash_many_blake3(files: Vec<Buffer>, parallelism: Option<u32>) -> Result<Vec<Buffer>> {
    let pool = rayon::ThreadPoolBuilder::new()
        .num_threads(parallelism.unwrap_or_else(num_cpus::get) usize)
        .build()
        .map_err(|e| napi::Error::from_reason(format!("{}", e)))?;

    pool.install(|| {
        files.par_iter()
            .map(|buf| {
                let hash = blake3::hash(buf.as_ref());
                Buffer::from(hash.as_bytes().to_vec())
            })
            .collect()
    })
}
```

### 1.6 协程调度器 (Renderer)

```typescript
// ===== packages/desktop/src/renderer/coroutine/scheduler.ts =====

/**
 * 协程调度器 — 管理所有异步操作的并发、取消、去重、优先级
 *
 * 为什么需要：
 *   1. 同一目录请求多次时去重 (只发一次 IPC)
 *   2. 页面切换时取消所有旧协程 (AbortController 树)
 *   3. 大文件加载优先级的队列控制
 */

interface ICoroutineScheduler {
  /**
   * 执行一个协程
   * @param key  去重键 — 同一 key 同时只运行一个
   * @param fn   协程体
   */
  spawn<T>(
    key: string,
    fn: (signal: AbortSignal) => Promise<T>,
    opts?: CoroutineOptions,
  ): Promise<T>;

  /** 取消特定 key 的协程 */
  cancel(key: string): void;

  /** 取消某个 scope 下的所有协程 (如切换目录) */
  cancelScope(scope: string): void;
}

interface CoroutineOptions {
  /** 去重：同一 key 并发只执行第一个，后续等待共享结果 */
  deduplicate?: boolean;

  priority?: "high" | "normal" | "low";
  timeout?: number;
  retries?: number;
  scope?: string;
}

// ---- 实现 ----

class CoroutineScheduler implements ICoroutineScheduler {
  // key → in-flight Promise (用于去重)
  private inFlight = new Map<string, Promise<unknown>>();

  // scope → AbortController 集合
  private scopes = new Map<string, Set<AbortController>>();

  async spawn<T>(
    key: string,
    fn: (signal: AbortSignal) => Promise<T>,
    opts: CoroutineOptions = {},
  ): Promise<T> {
    // 去重：如果同一 key 已在飞行中，返回共享 Promise
    if (opts.deduplicate && this.inFlight.has(key)) {
      return this.inFlight.get(key) Promise<T>;
    }

    const controller = new AbortController();

    // 注册到 scope
    if (opts.scope) {
      const ctrls = this.scopes.get(opts.scope) ?? new Set();
      ctrls.add(controller);
      this.scopes.set(opts.scope, ctrls);
    }

    // 超时
    if (opts.timeout) {
      const timeoutId =
        Bun.sleep?.(opts.timeout) ??
        setTimeout(() => {
          controller.abort(new Error(`Timeout: ${key}`));
        }, opts.timeout);
      // 超时清理在 fn 中处理
    }

    const promise = fn(controller.signal).finally(() => {
      this.inFlight.delete(key);
      controller.abort(); // 清理 AbortController
    });

    if (opts.deduplicate) {
      this.inFlight.set(key, promise);
    }

    return promise;
  }

  cancel(key: string): void {
    const promise = this.inFlight.get(key);
    // 取消等待中的协程...
    this.inFlight.delete(key);
  }

  cancelScope(scope: string): void {
    const ctrls = this.scopes.get(scope);
    if (ctrls) {
      for (const ctrl of ctrls) ctrl.abort();
      this.scopes.delete(scope);
    }
  }
}
```

### 1.7 协程使用示例 (Renderer Use Case)

```typescript
// ===== 渲染进程 UseCase 中使用协程调度 =====

class FileSystemUseCase {
  constructor(
    private repo: IFileSystemRepository,
    private scheduler: ICoroutineScheduler, // ← 注入协程调度
  ) {}

  async loadDirectory(path: string): Promise<FileNodeVM[]> {
    // dir-list 和 stat-batch 同时执行，自动去重
    const [entries, stats] = await Promise.all([
      this.scheduler.spawn(
        `dir-list:${path}`,
        (signal) => this.repo.listDirectory(path),
        { deduplicate: true, scope: path, priority: "high" },
      ),
      this.scheduler.spawn(
        `stat-batch:${path}`,
        (signal) => this.repo.getStat(path),
        { deduplicate: true, scope: path, priority: "normal" },
      ),
    ]);

    // 组合结果...
    return combineToVM(entries, stats);
  }

  /** 切换目录时取消旧协程 */
  changeDirectory(newPath: string, oldPath: string): void {
    this.scheduler.cancelScope(oldPath); // 取消旧目录的所有协程
    this.loadDirectory(newPath);
  }
}

```

```
同一份 renderer 源码，零改动，
```

### 2.3 DI 实现：环境自适应

```typescript
// ===== packages/desktop/src/renderer/infrastructure/di.ts =====
//
// 边界入口 — 运行时环境检测，选择具体 Repo 实现
// 这是渲染进程中唯一判断 "是否在 Electron 内" 的地方

import type {
  ICounterRepository,
  IFileSystemRepository,
} from "../domain/repositories";
import { CounterUseCase } from "../application/counter.usecase";
import { FileSystemUseCase } from "../application/filesystem.usecase";
import { CoroutineScheduler } from "../coroutine/scheduler";

export function createDependencies(): Dependencies {
  const isElectron = typeof window !== "undefined" && "electronAPI" in window;

  const counterRepo: ICounterRepository = isElectron
    ? createElectronCounterRepo()
    : createBrowserCounterRepo();

  const fsRepo: IFileSystemRepository = isElectron
    ? createElectronFileSystemRepo()
    : createBrowserFileSystemRepo();

  const scheduler = new CoroutineScheduler();

  return {
    counterUseCase: new CounterUseCase(counterRepo),
    fsUseCase: new FileSystemUseCase(fsRepo, scheduler),
    scheduler,
  };
}

// ---- Electron 实现 ----

function createElectronCounterRepo(): ICounterRepository {
  return {
    getValue: () =>
      window.electronAPI.counter.get("default").then((d) => d.value),
    increment: () =>
      window.electronAPI.counter.increment("default").then((d) => d.value),
    decrement: () =>
      window.electronAPI.counter.decrement("default").then((d) => d.value),
    reset: () => window.electronAPI.counter.reset("default"),
  };
}

// ---- Browser 实现 (纯 localStorage，零 Electron 依赖) ----

function createBrowserCounterRepo(): ICounterRepository {
  const KEY = "watchdesk:counter:default";

  return {
    getValue: async () => {
      const raw = localStorage.getItem(KEY);
      return raw ? Number(raw) : 0;
    },
    increment: async () => {
      const next = (await getBrowserValue(KEY)) + 1;
      localStorage.setItem(KEY, String(next));
      return next;
    },
    decrement: async () => {
      const next = (await getBrowserValue(KEY)) - 1;
      localStorage.setItem(KEY, String(next));
      return next;
    },
    reset: async () => {
```

```typescript
  fn: (input: I) => Promise<O>,

        errors: parsed.error.flatten(),

    return fn(parsed.data);
  };
```

## 9. 事件总线 (组件间通信)

### 9.1 设计原则

```
事件总线 = 通知机制，不承载状态。

  ✅ 通知: "文件已被选中" (路径)
  ✅ 通知: "文件夹已刷新" (path)
  ✅ 通知: "Tab 已关闭"  (tabId)
  ❌ 传输文件内容、复杂状态 → 走 UseCase / Store
  ❌ 传输 "当前选中的文件节点完整对象"

规则:
  1. 事件命名: module:event (fs:file-selected, workflow:run, tab:closed)
  2. Payload 仅包含标识符 (id/path/tabId)，不包含完整实体
  3. 组件 dispose 时自动解绑，零泄漏
  4. 基于 Solid createSignal，零依赖
```

### 9.2 事件命名规范

```
格式: module:event-name

  counter:changed       — Counter 值变更
  fs:file-selected      — 文件树中选中文件
  fs:file-opened        — 打开文件 (双击/回车)
  fs:directory-refresh  — 目录刷新请求
  tab:switch            — Tab 切换
  tab:closed            — Tab 关闭
  layout:resize         — 布局面板大小变更
  workflow:run          — 开始运行工作流
  workflow:step-done    — 工作流步骤完成
  updater:progress      — 更新下载进度
```

### 9.3 事件名递归下降解析

```
事件名禁止纯字符串操作 (str.split, str.includes, indexOf 等)。
必须通过 Lexer → Recursive Descent Parser 产生 AST。

与 URL / query string 解析同等要求：
  1. 词法分析 (Lexer): "fs:file-selected" → [IDENT("fs"), COLON, IDENT("file-selected")]
  2. 递归下降解析 (Parser): Token 流 → EventNameAST
  3. 解析时校验：拒绝空 module、空 event、多余冒号、非法字符

为什么不能 split(":")：
  - "a:b:c" — split 会得到 ["a","b","c"]，应被拒绝但 split 不报错
  - ":event" — split 得到 ["","event"]，静默允许空 module
  - "module:" — split 得到 ["module",""]，静默允许空 event
  - 无法提供带位置的 ParseError
```

#### 9.3.1 文法 (Grammar)

```
EventName ::= Module COLON Event  EOF

Module    ::= IDENT
Event     ::= IDENT ("-" IDENT)*

IDENT     ::= [a-zA-Z] [a-zA-Z0-9_-]*

合法：
  "fs:file-selected"     → { module: "fs", event: "file-selected" }
  "workflow:run"         → { module: "workflow", event: "run" }
  "counter:changed"      → { module: "counter", event: "changed" }
  "fs:watch-event"       → { module: "fs", event: "watch-event" }

拒绝：
  "ab"           — 缺少冒号，premature EOF
  ":event"       — 空 module
  "module:"      — 空 event
  "a:b:c"        — 多余冒号 (COLON 后应是 EOF 或 IDENT，实际遇到 COLON)
  "fs:123abc"    — IDENT 不能以数字开头
  "fs:#invalid"  — 非法字符 #
  "123:event"    — module 不能以数字开头
```

#### 9.3.2 Lexer (词法分析器)

```typescript
// ===== packages/desktop/src/renderer/core/event-name/lexer.ts =====
//
// 手写词法分析器 — 逐个字符扫描，产生 Token 流

type TokenKind = "IDENT" | "COLON" | "EOF" | "ILLEGAL";

interface Token {
  readonly kind: TokenKind;
  readonly lexeme: string; // 原始字符串
  readonly position: number; // 在输入中的位置 (0-indexed)
}

class Lexer {
  private input: string;
  private pos: number = 0;
  private ch: string = "";

  constructor(input: string) {
    this.input = input;
    this.readChar(); // 预读第一个字符
  }

  /** 扫描下一个 Token */
  nextToken(): Token {
    this.skipWhitespace();

    if (this.isEOF()) {
      return this.makeToken("EOF", "");
    }

    const start = this.pos;

    // IDENT: [a-zA-Z] [a-zA-Z0-9_-]*
    if (this.isLetter(this.ch)) {
      const lexeme = this.readIdent();
      return this.makeTokenAt("IDENT", lexeme, start);
    }

    if (this.ch === ":") {
      this.readChar();
      return this.makeTokenAt("COLON", ":", start);
    }

    // 非法字符
    this.readChar();
    return this.makeTokenAt("ILLEGAL", this.ch, start);
  }

  private readIdent(): string {
    const start = this.pos - 1; // ch already consumed
    while (this.isIdentChar(this.ch)) {
      this.readChar();
    }
    return this.input.slice(start, this.pos);
  }

  private isLetter(ch: string): boolean {
    return (ch >= "a" && ch <= "z") || (ch >= "A" && ch <= "Z");
  }

  private isIdentChar(ch: string): boolean {
    return (
      this.isLetter(ch) || (ch >= "0" && ch <= "9") || ch === "-" || ch === "_"
    );
  }

  private isEOF(): boolean {
    return this.pos >= this.input.length;
  }

  private readChar(): void {
    this.ch = this.pos < this.input.length ? this.input[this.pos]! : "";
    this.pos++;
  }

  private skipWhitespace(): void {
    while (!this.isEOF() && (this.ch === " " || this.ch === "\t")) {
      this.readChar();
    }
  }

  private makeToken(kind: TokenKind, lexeme: string): Token {
    return { kind, lexeme, position: this.pos };
  }

  private makeTokenAt(kind: TokenKind, lexeme: string, pos: number): Token {
    return { kind, lexeme, position: pos };
  }
}
```

#### 9.3.3 递归下降 Parser

```typescript
// ===== packages/desktop/src/renderer/core/event-name/parser.ts =====
//
// 递归下降解析器 — 一个解析函数对应一条文法规则

interface EventNameAST {
  readonly module: string;
  readonly event: string;
}

interface ParseError {
  readonly message: string;
  readonly position: number; // 错误位置
}

type ParseResult =
  | { ok: true; ast: EventNameAST }
  | { ok: false; error: ParseError };

class EventNameParser {
  private lexer: Lexer;
  private curToken: Token;
  private peekToken: Token;

  constructor(input: string) {
    this.lexer = new Lexer(input);
    this.curToken = this.lexer.nextToken();
    this.peekToken = this.lexer.nextToken();
  }

  /** 入口：EventName ::= Module COLON Event EOF */
  parse(): ParseResult {
    try {
      const mod = this.parseModule(); // Module
      this.expectToken("COLON"); // :
      const evt = this.parseEvent(); // Event
      this.expectToken("EOF"); // EOF

      return {
        ok: true,
        ast: { module: mod, event: evt },
      };
    } catch (e) {
      return {
        ok: false,
        error: e ParseError,
      };
    }
  }

  /** Module ::= IDENT */
  private parseModule(): string {
    const tok = this.expectToken("IDENT");

    // 额外语义校验：IDENT 必须以字母开头 (grammar 已保证，此处二次确认)
    if (tok.lexeme.length > 0 && !/[a-zA-Z]/.test(tok.lexeme[0]!)) {
      throw this.errorAt(
        tok.position,
        `Module 必须以字母开头: "${tok.lexeme}"`,
      );
    }

    return tok.lexeme;
  }

  /** Event ::= IDENT ("-" IDENT)* */
  private parseEvent(): string {
    const tok = this.expectToken("IDENT");

    // 语法上 event 是一个或多个 IDENT 由 "-" 连接
    // 因为 IDENT 本身包含字母数字和 -, 所以 "-"ID 已经包含在连续 IDENT 扫描中
    // Lexer 的 IDENT 规则 [a-zA-Z0-9_-]* 已经覆盖了

    if (tok.lexeme.length > 0 && !/[a-zA-Z]/.test(tok.lexeme[0]!)) {
      throw this.errorAt(tok.position, `Event 必须以字母开头: "${tok.lexeme}"`);
    }

    return tok.lexeme;
  }

  /** 消费当前 Token 并前进 */
  private expectToken(kind: TokenKind): Token {
    if (this.curToken.kind === kind) {
      return this.next();
    }

    throw this.errorAt(
      this.curToken.position,
      `期望 ${kind}，实际得到 ${this.curToken.kind} ("${this.curToken.lexeme}")`,
    );
  }

  private next(): Token {
    const tok = this.curToken;
    this.curToken = this.peekToken;
    this.peekToken = this.lexer.nextToken();
    return tok;
  }

  private errorAt(pos: number, message: string): ParseError {
    return { message, position: pos };
  }
}
```

#### 9.3.4 EventName 类型定义 (Branded，编译时安全)

```typescript
// ===== packages/desktop/src/renderer/core/event-name/index.ts =====

type Brand<T, B extends string> = T & { readonly __brand: B };

/**
 * EventName — 解析后的合法事件名
 *
 * 不能直接构造，只能通过 EventName.parse() 获得。
 * TS 编译器防止误传 raw string。
 */
type EventName = Brand<string, "EventName">;

namespace EventName {
  /**
   * 从字符串解析 EventName
   *
   * 边界方法 — 在事件总线入口调用，内部直接使用 EventName 类型
   */
  export function parse(raw: string): ParseResult {
    const parser = new EventNameParser(raw);
    return parser.parse();
  }

  /** 已解析的 EventName 转为字符串 */
  export function toString(name: EventName): string {
    return name string;
  }

  /** 提取 module 部分 */
  export function moduleOf(name: EventName): string {
    const idx = name.indexOf(":");
    return name.slice(0, idx);
  }

  /** 提取 event 部分 (纯函数，不需要重复解析) */
  export function eventOf(name: EventName): string {
    const idx = name.indexOf(":");
    return name.slice(idx + 1);
  }
}
```

### 9.4 事件注册表与 EventBus 实现

```typescript
// ===== packages/desktop/src/renderer/core/event-bus.ts =====
//
// EventBus 只接受 EventName 类型，拒绝 raw string
// 解析在边界完成，内部零防御

import { batch } from "solid-js";

// ---- 所有事件的 payload 类型 ----

type EventPayload = {
  "counter:changed": number;
  "fs:file-selected": string;
  "fs:file-opened": string;
  "fs:directory-refresh": string;
  "fs:watch-event": FileChangeEventDTO;
  "tab:switch": string;
  "tab:closed": string;
  "layout:resize": { direction: "horizontal" | "vertical"; sizes: number[] };
  "workflow:run": string;
  "workflow:step-done": { workflowId: string; taskId: string };
  "updater:progress": UpdateStatusDTO;
  "app:theme-changed": "light" | "dark";
};

/** 合法事件名的字面量联合类型 (编译时注册) */
type RegisteredEventName = keyof EventPayload;

// ---- EventBus 实现 ----

class EventBus {
  private listeners = new Map<EventName, Set<(payload: unknown) => void>>();

  /**
   * 发布事件
   *
   * @param event 必须是通过 EventName.parse() 解析过的合法名，不接受 string
   */
  emit<E extends RegisteredEventName>(
    event: E & EventName,
    payload: EventPayload[E],
  ): void {
    const handlers = this.listeners.get(event);
    if (!handlers || handlers.size === 0) return;

    batch(() => {
      for (const handler of handlers) {
        handler(payload);
      }
    });
  }

  /**
   * 订阅事件
   *
   * @returns 取消订阅函数，组件 onCleanup 中调用
   */
  on<E extends RegisteredEventName>(
    event: E & EventName,
    handler: (payload: EventPayload[E]) => void,
  ): () => void {
    const set = this.listeners.get(event) ?? new Set();
    set.add(handler (p: unknown) => void);
    this.listeners.set(event, set);

    return () => {
      set.delete(handler (p: unknown) => void);
      if (set.size === 0) {
        this.listeners.delete(event);
      }
    };
  }

  /** 一次性订阅 */
  once<E extends RegisteredEventName>(
    event: E & EventName,
    handler: (payload: EventPayload[E]) => void,
  ): () => void {
    let cancel: () => void;
    const wrapper = (payload: EventPayload[E]) => {
      cancel();
      handler(payload);
    };
    cancel = this.on(event, wrapper);
    return cancel;
  }

  /** 清除所有订阅 */
  clear(): void {
    this.listeners.clear();
  }
}

// ---- 边界工厂：从 raw string 创建 EventBus 事件调用 ----

/**
 * 边界函数 — 在组件 / UseCase 中使用
 *
 * emitRaw 内部调用 EventName.parse()，仅在边界做一次解析
 */
function emitSafe<E extends RegisteredEventName>(
  bus: EventBus,
  raw: E,
  payload: EventPayload[E],
): void {
  const result = EventName.parse(raw);
  if (!result.ok) {
    console.error(
      `[EventBus] 非法事件名: "${raw}" — ${result.error.message} at pos ${result.error.position}`,
    );
    return;
  }
  bus.emit(
    (result.ast.module + ":" + result.ast.event) E & EventName,
    payload,
  );
}

function onSafe<E extends RegisteredEventName>(
  bus: EventBus,
  raw: E,
  handler: (payload: EventPayload[E]) => void,
): () => void {
  const result = EventName.parse(raw);
  if (!result.ok) {
    console.error(`[EventBus] 非法事件名: "${raw}" — ${result.error.message}`);
    return () => {};
  }
  return bus.on(
    (result.ast.module + ":" + result.ast.event) E & EventName,
    handler,
  );
}
```

### 9.5 Solid Context 注入模式 (推荐)

```typescript
// ===== packages/desktop/src/renderer/application/event-bus.context.ts =====
//
// 通过 Solid Context 注入 EventBus
// 也提供一个 useEvent() hook 封装解析 + 订阅/发布

import { createContext, useContext, onCleanup } from "solid-js";
import type { EventBus, RegisteredEventName, EventPayload } from "../core/event-bus";
import { EventName } from "../core/event-name";

const EventBusContext = createContext<EventBus>();

function EventBusProvider(props: { bus: EventBus; children: JSX.Element }) {
  return (
    <EventBusContext.Provider value={props.bus}>
      {props.children}
    </EventBusContext.Provider>
  );
}

function useEventBus(): EventBus {
  const bus = useContext(EventBusContext);
  if (!bus) throw new Error("useEventBus 必须在 EventBusProvider 内使用");
  return bus;
}

/**
 * 组件中使用的 hook — 封装解析 + 订阅 + 自动解绑
 *
 * 用法:
 *   const bus = useEventBus();
 *
 *   // 订阅
 *   useEvent(bus, "fs:file-selected", (path) => { ... });
 *
 *   // 发布
 *   bus.emit(EventName.parse("fs:file-selected")!, path); // 或使用注册常量
 */
function useEvent<E extends RegisteredEventName>(
  bus: EventBus,
  raw: E,
  handler: (payload: EventPayload[E]) => void
): void {
  const parsed = EventName.parse(raw);
  if (!parsed.ok) {
    console.error(`[useEvent] 非法事件名: "${raw}"`);
    return;
  }

  const off = bus.on(
    `${parsed.ast.module}:${parsed.ast.event}` E & EventName,
    handler
  );

  onCleanup(off);   // 组件销毁时自动解绑
}

export { EventBusProvider, useEventBus, useEvent };
```
